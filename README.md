# Universal RAG AI Knowledge Assistant

Powered by Groq AI | Hybrid RRF Vector Search | Enterprise Governance

Upload research papers, resumes, technical reports, or corporate documents to build a context-grounded AI knowledge base with strict departmental upload governance.

## Features
- Multi-format ingestion: PDF, DOCX, TXT, CSV, Excel
- Hybrid RRF Search: Semantic (FAISS) + Keyword search
- Departmental RBAC: Admin / HR Head / Finance Head / Staff upload permissions
- Governance Dashboard: Live audit log, staleness tracking, department stats
- Groq LLM: Ultra-fast inference with model fallback

## Setup
Set your GROQ_API_KEY in the Space Settings -> Secrets tab.
